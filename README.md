# 🚢 Rio Ops — Sistema de Missões Fluviais

> Sistema operacional completo para missões de patrulha fluvial na Amazônia.  
> 100% offline · Android APK · PWA fullscreen

---

## 📁 Arquivos

| Arquivo | Descrição |
|---|---|
| `index.html` | Aplicativo completo |
| `sw.js` | Service Worker — offline |
| `manifest.json` | Configuração PWA — fullscreen |
| `README.md` | Documentação |

---

## 🚀 Publicar no GitHub Pages

1. Faça upload dos 4 arquivos no repositório
2. **Settings → Pages → Branch: main → Save**
3. Aguarde 3–5 min
4. URL: `https://altierisoaresmariano-bit.github.io/RioOps`

---

## 📱 Gerar APK

1. Acesse [median.co](https://median.co) ou [pwabuilder.com](https://pwabuilder.com)
2. Cole a URL do GitHub Pages
3. Gere e baixe o `.apk`
4. Instale no Android
